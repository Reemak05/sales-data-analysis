# Sales Data Analysis

## Overview

A Python-based sales data analysis project that processes sales data
and extracts useful business insights using Python, Pandas, and NumPy.

This project is being developed step by step as part of a Data Science
learning roadmap.

## Objectives

- Calculate total revenue
- Calculate average product price
- Calculate total quantity sold
- Identify the best-selling product
- Analyze revenue by city
- Analyze revenue by category
- Identify the most expensive and cheapest products
- Filter products based on price
- Practice data analysis using Pandas and NumPy

## Technologies

- Python
- Pandas
- NumPy
- CSV
- Git
- GitHub
